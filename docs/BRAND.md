# CritForge · identidade visual

[← Voltar](../README.md)

## Nome e posicionamento

**CritForge** une *crit*, referência ao acerto crítico nos jogos, e *forge*, a oficina onde uma ideia ganha forma. A assinatura **From character to tabletop** resume o percurso da referência à miniatura de jogo.

O nome público é CritForge. O identificador técnico permanece `meshy-miniaturas`: pasta da skill, frontmatter e invocação continuam compatíveis. O repositório público é `eep0x10/critforge`. Não há declaração de exclusividade ou registro de marca.

## Direção de arte

| Elemento | Papel |
| :--- | :--- |
| Carvão escuro `#121A20` | Fundo de oficina, contraste e profundidade |
| Marfim | Nome e escultura, com leitura clara |
| Âmbar `#C89B57` | Marca geométrica e pequenos detalhes |
| Verde sálvia discreto | Guias e desenhos técnicos |
| Escultura cinza sem base | O domínio real do projeto: miniaturas para resina |

Evitar excesso de badges, efeitos neon, estatísticas sem medição e qualquer imagem que pareça comprovar uma impressão não realizada.
